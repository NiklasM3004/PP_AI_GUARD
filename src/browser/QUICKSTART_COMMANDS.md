# ⚡ Quick Start Commands

## 1️⃣ Test-Seite starten
```bash
cd ~/Downloads
python3 -m http.server 8000
```
→ Öffne: http://localhost:8000/test_chat.html

## 2️⃣ Icons erstellen (Online)
→ Gehe zu: https://cloudconvert.com/svg-to-png
→ Upload: extension/icons/icon.svg
→ Erstelle 3 Größen: 16x16, 48x48, 128x128

## 3️⃣ Extension laden
1. Chrome: chrome://extensions/
2. "Entwicklermodus" AN
3. "Entpackte Erweiterung laden"
4. Wähle den "extension" Ordner

## 4️⃣ Testen
1. Öffne Test-Seite
2. F12 → Console Tab
3. Schreibe Nachricht
4. Klicke "Senden"
5. ✅ Sieh Console-Log!
